# **App Name**: EkklesiaConnect

## Core Features:

- User Registration: Allows new users to register with Korean name, English name, title (with options for no title, deacon, elder, pastor), title appointment date, phone number, email, address (Address 1, address 2, city, state, zip), and family relations. Cross-validation will occur based on name and address.
- Group & Individual Chat: Enable individual and group chats with specific channels for different departments (Worship, Education, Finance, Mission, Fellowship, Management).
- Access Control: Implement access control: Senior Elders and the Lead Pastor can view all group chats, while regular members can only view groups they belong to.
- File and Photo Sharing: Allow users to share files and photos in chats. Display thumbnails for images within the chat interface.
- Admin Announcements: Enable admins to send announcements to individual users within the application.
- Tithing Records: Each user can view their own tithing records for a specified period. Only finance elders can input, modify, and delete tithing records.
- AI-Powered Hymnal and Bible Search: Tool to quickly search through the integrated Korean/English hymnal (with copyright-free sheet music and lyrics sourced and database) and Revised Korean Bible using the AI LLM's information retrieval abilities.
- Sermon Streaming: Display sermons with YouTube link integration, showing a thumbnail and allowing full-screen viewing. Permission to add sermon links restricted to Senior Elders.
- Weekly Bulletin: Dedicated bulletin screen updated weekly via PDF, JPG, or PNG uploads.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5), symbolizing trust, stability, and spirituality, resonating with church values.
- Background color: Light blue (#E3F2FD), creating a serene and peaceful atmosphere.
- Accent color: Soft purple (#9575CD), offering a touch of elegance and reverence.
- Body and headline font: 'PT Sans', a modern, yet warm humanist sans-serif font, for easy readability.
- Use clean, modern icons for navigation and features, ensuring they are easily recognizable.
- Mimic the layout of KakaoTalk for familiarity, with intuitive navigation for all age groups.
- Subtle, respectful animations to enhance user experience without being distracting.
